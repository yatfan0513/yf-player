# 📺 全能視頻播放器與 M3U 管理工具集

本項目是一個純前端、完全離線可用的多功能媒體工具集，專為 IPTV 愛好者及日常觀看電視直播、點播視頻而設計。所有功能均在瀏覽器本地執行，不上傳任何數據。

## 📁 專案結構

```text
├── admin.html          # 基礎 M3U 管理工具（離線編輯、新增、匯出）
├── m3u-manager.html    # 進階 M3U 播放清單管理工具（批次匯入、去重、有效性檢測）
├── index.html          # 全能視頻播放器（支援 HLS、網頁嗅探、倍速、縮放）
├── hls.min.js          # HLS.js 核心庫
├── hls.worker.js       # HLS.js Web Worker 腳本
├── playlist.m3u        # 預設播放清單
├── merged.m3u          # 合併後的播放清單
├── jueduiquanli.m3u    # 自訂頻道清單
├── renmindemingyi.m3u  # 自訂頻道清單
└── zhigaoliyi.m3u      # 自訂頻道清單
```

## 🚀 核心功能介紹

### 1. 全能視頻播放器 (`index.html`)
- **多格式支援**：支援 M3U8、M3U、HTTP/HTTPS 影片、音頻及圖片。
- **HLS.js 引擎**：內建 HLS.js 引擎，並支援跨域代理回退機制，解決部分裝置原生不支援 HLS 的問題。
- **網頁嗅探**：輸入網頁地址，自動嗅探並提取網頁中的 `.m3u8`、`.mp4` 等媒體資源。
- **強大控制**：支援自訂倍速播放（最高 3.0x）、精確跳轉、多段快進/倒退（+/- 5s 至 5min）。
- **畫面縮放**：支援自訂畫面縮放比例（0-100%），並可切換純黑、純白、深藍等多種背景主題。
- **清單解析**：支援直接載入 M3U 網址，並對頻道進行併發有效性檢測。

### 2. 基礎 M3U 管理工具 (`admin.html`)
- **純離線運作**：完全在瀏覽器記憶體中執行。
- **本地匯入**：選擇本地 `.m3u` 檔案。
- **頻道管理**：支援新增、編輯、刪除頻道（自動檢查名稱重複）。
- **安全匯出**：將編輯後的頻道清單匯出為帶有 UTF-8 BOM 的 `playlist.m3u`。

### 3. 進階 M3U 播放清單管理工具 (`m3u-manager.html`)
- **多源匯入**：支援批次拖曳本地檔案，或輸入多個 M3U 網址（需支援 CORS）。
- **解析與去重**：自動解析 `#EXTINF` 標籤，按播放地址進行完全一致的去重，並按頻道名稱自然排序。
- **有效性檢測**：
  - 提供「相容模式」、「平衡模式」、「極速模式」三種併發速度選擇。
  - 基於 CPU 執行緒數動態調整併發數。
  - 檢查 HTTP 狀態碼及內容是否包含 HLS 特徵（如 `#EXTM3U`）。
- **進度與統計**：即時顯示檢查進度條及匯入、有效、無效、去重統計數據。
- **分組預覽**：按頻道名稱分組，支援搜尋及狀態篩選（全部、有效、無效、待檢查）。
- **智慧匯出**：檢查完成後優先匯出「有效」線路；未檢查前匯出全部去重線路，生成 `merged.m3u`。

## 🛠️ 使用方式

1. **直接開啟**：將所有檔案下載至本地資料夾，直接雙擊 `index.html`、`admin.html` 或 `m3u-manager.html` 即可在瀏覽器中使用。
2. **線上訪問**：可直接透過 GitHub Pages 訪問（見下方連結）。
3. **注意事項**：
   - RTSP / RTMP 協議無法直接在瀏覽器中播放，需先轉換為 HLS 格式。
   - 網頁嗅探與遠端 M3U 讀取受限於目標網站的 CORS 策略，部分網站可能需要透過代理讀取。
